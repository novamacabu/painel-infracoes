› Conectar dados reais (webhook Make)

Integração já configurada. O cenário 📊 Painel de Infrações — API de Dados (Webhook) (ID 6045567) foi criado na sua conta Make e está ativo. Ele usa a conexão SharePoint existente, lê as três listas (Área Restrita, Velocidade Excedida e Cadastro Motoristas) e responde a este painel — somente leitura, sem tocar no cenário de notificação por WhatsApp.

Cada clique em Atualizar dados consome 8 créditos Make (1 webhook + 3 leituras + 3 conversões JSON + 1 resposta) e traz o retrato atual de até 500 itens por lista.

Se a atualização falhar, verifique no Make se o cenário ID 6045567 está ligado (ON) e se a conexão "Nova Macabu SharePoint" está válida. Importante: este arquivo deve ser aberto diretamente no navegador (Chrome/Edge) — dentro de visualizadores restritos a chamada externa é bloqueada.

Segurança: a URL do webhook não aparece no código-fonte — ela é decifrada pela senha no momento do login (AES-256). Para revogar todo acesso, exclua o webhook no Make; para trocar senhas ou adicionar usuários, gere novos blocos criptografados (peça ao assistente do projeto).
