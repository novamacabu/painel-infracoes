› Conexão com o SharePoint (webhook Make)

Integração configurada. O painel lê as três listas do SharePoint (Área Restrita, Velocidade Excedida e Cadastro Motoristas) pelo cenário 📊 Painel de Infrações — API de Dados no Make — somente leitura. O botão Disparar envio aciona o cenário 🟢 Envio das Infrações por WhatsApp.

Cada Atualizar dados consome ~8 créditos Make; cada Disparar envio consome os créditos normais do envio.

Se a atualização falhar, verifique no Make se os cenários estão ligados (ON) e se a conexão "Nova Macabu SharePoint" está válida. Este arquivo deve ser aberto diretamente no navegador.

Segurança: as URLs dos webhooks não aparecem no código-fonte — são decifradas pela senha no momento do login (AES-256). Para revogar todo acesso, exclua os webhooks no Make.
