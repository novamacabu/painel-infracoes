› Conectar dados reais (webhook Make)

Integração já configurada. O cenário 📊 SAC Nova Macabu - Painel (API de Dados) (ID 6145564) está ativo na conta Make. Ele usa a conexão SharePoint do SAC, lê a lista Chamados (site /sites/SAC) e responde a este painel — somente leitura, sem tocar nos cenários de captura.

Edições do painel (fixar, notificação ao passageiro, comentários e 1ª resposta) gravam direto na lista pelo cenário ✏️ SAC Nova Macabu - Painel (Escrita) (ID 6148487) — ~3 operações por edição, também protegido pelo login. Para revogar só a escrita, desligue esse cenário no Make.

Cada clique em Atualizar dados consome ~4 operações Make (webhook + leitura + JSON + resposta) e traz o retrato atual de até 500 chamados.

Se a atualização falhar, verifique no Make se o cenário ID 6145564 está ligado (ON) e se a conexão SharePoint do SAC está válida. Importante: este arquivo deve ser aberto diretamente no navegador (Chrome/Edge) ou via GitHub Pages — dentro de visualizadores restritos a chamada externa é bloqueada.

Segurança e privacidade: a lista Chamados contém dados pessoais (nome, CPF, contato); por isso a URL do webhook não aparece no código-fonte — ela é decifrada pela senha no momento do login (AES-256-GCM). Nenhum dado fica gravado no repositório. Para revogar todo acesso, exclua o webhook no Make; para trocar senhas ou adicionar usuários, gere novos blocos criptografados (peça ao assistente do projeto).
